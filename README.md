# Personal Expense Tracker

A personal expense management application built using the MERN stack.

## Technologies Used

* MongoDB
* Express.js
* React.js
* Node.js
* Bootstrap

## Features

* Add income and expenses
* View transaction history
* Edit transactions
* Delete transactions
* Calculate balance, total income, and expenses
* Filter transactions by category
