# Personal Expense Tracker

## About the Project

The Personal Expense Tracker is a MERN Stack web application that helps users record and manage their daily income and expenses.

## Technologies Used

* **MongoDB** – Stores transaction data
* **Express.js** – Handles backend API requests
* **React.js** – Builds the user interface
* **Node.js** – Runs the backend server
* **Bootstrap** – Styles the application

## Features

1. Add income and expense transactions
2. View transaction history
3. Edit existing transactions
4. Delete transactions
5. Calculate total income, total expenses, and balance
6. Filter transactions by category
7. Store transactions in MongoDB

## Project Structure

* `client/` – React frontend
* `server/` – Node.js and Express backend

## How to Run Locally

1. Install Node.js.
2. Install the frontend dependencies using `npm install` inside the client folder.
3. Install the backend dependencies using `npm install` inside the server folder.
4. Configure the MongoDB connection string in the backend `.env` file.
5. Start the backend and frontend servers.
6. Open the local frontend URL in your browser.

## Project Purpose

This project demonstrates CRUD operations, REST API development, database integration, and frontend-backend communication using the MERN stack.
